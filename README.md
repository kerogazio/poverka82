# ПРОМЕТР — статичный SEO-сайт

## Страницы
- `/simferopol/` — посадочная под Симферополь
- `/sevastopol/` — посадочная под Севастополь
- `/murmansk/` — посадочная под Мурманск
- `/` — обычная общая страница услуги, **без выбора города**

## Перед публикацией
1. После подключения домена заменить адрес GitHub Pages в `robots.txt` и `sitemap.xml` на реальный домен.
2. Canonical URL на каждой странице уже добавлены (домен `поверкасчётчиков-82.рф`, в punycode — как в `sitemap.xml`). При смене домена обновить их.
3. Подключить Яндекс Метрику / Google Search Console / Яндекс Вебмастер.
4. Сейчас основной CTA — звонок. Для форм заявок понадобится внешний endpoint / webhook.
